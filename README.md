# Campaign_Performance_Analytics
Interactive Power BI dashboard showcasing campaign performance across regions with RFM segmentation, discount impact, and conversion analysis. Includes SQL-driven customer scoring, ROI trends, and behavioural insights for strategic targeting and portfolio presentation.

---

## Overview

This dashboard visualizes:
- Revenue and ROI trends across Asia, Europe, and North America
- Customer segmentation using RFM (Recency, Frequency, Monetary) scoring
- Performance metrics: impressions, clicks, units sold, and revenue

---

## Tools & Technologies

- **Power BI**: Dashboard design, DAX measures, interactive visuals
- **SQL**: RFM scoring logic, campaign metric aggregation
- **Excel/CSV**: Data preparation and import
- **GitHub**: Version control and portfolio hosting

---

## Key Features

- Dynamic RFM segmentation with DAX and SQL
- Revenue vs. discount bucket analysis
- Region-wise ROI and revenue breakdown
- Pie chart of monetary rank by region
- Executive summary and stakeholder-ready layout
